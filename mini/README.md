# 💊 吃药提醒 · 微信小程序版 (med-reminder-mini)

轻量版用药打卡小程序：**今日打卡 + 日历回看 + 药品管理**，数据通过微信云开发
按微信号（openid）隔离存储。换手机后登录同一微信，数据自动拉回，无需任何服务器。

> 与 `med-reminder`（Android APK / PWA 版）的关系：本目录是独立的小程序项目，
> 砍掉了 OCR 识别与系统本地通知（小程序平台不支持），聚焦「跨设备随时查看与打卡」。

## 三步部署

### 1. 注册小程序并开通云开发（约 10 分钟，免费）

- 注册地址：https://mp.weixin.qq.com（选「小程序」，个人主体即可，无需认证）
- 拿到 **AppID**（小程序后台 → 开发 → 开发设置）
- 微信开发者工具：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
  （下载 → 用你的微信扫码登录 → 创建项目时填入 AppID）

### 2. 导入本项目并填 AppID（关键，别用测试号）

1. 开发者工具 → 导入项目 → 选择本目录 `med-reminder/mini`
2. **AppID 一栏必须填你自己的 AppID**（小程序后台 → 开发 → 开发设置）。
   如果用了「测试号/游客模式」，工具栏不会出现「云开发」按钮，后续全部没法做。
   已经用测试号打开的话：删除项目重新导入，或在「详情 → 基本信息」里修改 AppID。
3. 工具栏点 **云开发** → 开通（首次要创建环境，计费方式选「按量计费」，免费额度内零费用）
4. 复制你的**环境 ID**（云开发控制台 → 设置 → 环境 ID，形如 `xxx-1a2b3c`）
5. 打开 `miniprogram/utils/config.js`，把 `ENV_ID` 改成你的环境 ID，保存

### 3. 建数据库集合并部署云函数

1. 云开发控制台 → 数据库 → 新建集合，名字填 **`meduser`**
2. 该集合权限选 **「仅创建者可读写」**（云函数不受此限制，仍可读写任意用户记录，实现按 openid 隔离）
3. 回到开发者工具，在资源管理器里找到 `cloudfunctions/sync` 文件夹
   → **右键 → 上传并部署（云端安装依赖）**
4. 点工具栏「预览」，生成二维码，手机微信扫码即可真机使用

> 换手机：在新手机微信里打开同一个小程序（或从「发现 → 小程序」搜索进入），
> 数据会自动从云端拉回。

## 数据模型

- 云数据库集合 `meduser`：每用户一个文档，`_id = openid`
- 文档内容：`{ payload: { meds[], logs[] }, updatedAt }`
- 前端本地缓存同构数据；冷启动先渲染本地再拉云端合并（同 id 取 `updatedAt` 新者），
  操作后 1.2s 防抖上传，既快又省流量

## 为什么没有提醒？

微信小程序 **没有系统级本地通知**：标准「订阅消息」需用户每次授权一次只能推一条，
不适合每天多次的服药提醒。如果以后需要提醒，可考虑给这条小程序接入服务端定时推送
（需要企业主体 + 自有服务器）。当前版本专注「记录随时可查」。
